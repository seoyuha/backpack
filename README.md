# ⚔ English Backpack Battle — 영어로 성장하는 모험의 가방 대전

초등 6학년 영어 10~12단원 복습 게임이에요. 영어 퀴즈로 골드를 모아 장비를 사고, 가방에 배치·조합해서 몬스터와 자동 전투를 벌여요.

- 게임 주소: https://seoyuha.github.io/backpack/
- `index.html` 한 파일에 그림·글꼴·배경음·효과음·문제가 모두 들어 있어요.
- 가로 화면 태블릿·크롬북·PC 브라우저에서 실행해요.

## 수업 흐름
1. 학생: **개인전** → 캐릭터 선택 → 닉네임(+방 코드) → 게임 시작 → 대기실
2. 교사: **교사 모드** → 단원 고르기 → [방 만들기] → 학생 문제가 바로 바뀜 → [게임 시작]
3. 게임 중 일부 학생에게 ⚡깜짝 이벤트(학생 검색 1:1 대결 · 팀 섞기)가 무작위로 떠요.

## 문제 바꾸기
`questions_10_12.csv`를 엑셀에서 고친 뒤 교사 모드 › 문제 관리 › 엑셀로 문제 가져오기.
열: 단원, 난이도(1~3), 문제, 보기1~4, 정답번호(1~4), 문항유형

## 태블릿끼리 연결 (Firebase)
`index.html` 안의 `const FIREBASE_CONFIG=null;`을 Firebase 웹 앱 설정값으로 바꾸면 교사 화면과 학생 태블릿이 방 코드로 연결돼요.
Realtime Database 규칙 예: `{ "rules": { "ebb": { ".read": true, ".write": true } } }`
현재 Firebase 프로젝트 backpack-battle-3732d(싱가포르)에 연결돼 있어요. 규칙은 ebb 칸만 읽기·쓰기를 허용해요.
